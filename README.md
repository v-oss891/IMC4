# 🚀 IMC4 – Algorithmic Trading & Python Strategies

A collection of Python-based algorithmic trading strategies, simulations, and problem-solving implementations.

---

## 📌 Overview

This repository contains implementations of trading algorithms and quantitative techniques including Monte Carlo simulations, market making strategies, and data-driven models.

It is designed to demonstrate:

* Strong problem-solving skills
* Understanding of quantitative finance
* Clean and structured Python coding

---

## 🧠 Features

* 📊 Monte Carlo Trading Simulation
* ⚡ Market Making Strategies
* 🧮 Custom Data Models
* 🧪 Unit Testing for Strategies
* 🔍 Experimentation with trading logic

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/v-oss891/IMC4.git
cd IMC4
```

2. Install dependencies (if any):

```
pip install -r requirements.txt
```

---

## ▶️ Usage

Run a trading simulation:

```
python monte_carlo_trader.py
```

Run tests:

```
python test_trader.py
```
